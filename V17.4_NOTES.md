# TYSHI ZONE v17.4 (includes the v17.3 work)

## Do these steps after deploying
1. **Firestore rules**: copy `firestore.rules` into Firebase console → Firestore → Rules → Publish. New in this version: `adminConfig` (admin-only saved server patterns), `adminLog` (admin-only activity log), `presence` (each visitor can only write their own "watching now" document; only admins can read), `siteStats/visits` (+1 counter; only admins can read). Nothing existing was loosened: visitors still cannot write anime, episodes, series, siteConfig, other people's requests, or server patterns.
2. **Admin assistant (optional, off by default)**: in Netlify → Site configuration → Environment variables add `ASSISTANT_ENABLED=true` and `ANTHROPIC_API_KEY=<your key>` (optionally `ASSISTANT_MODEL`). The key lives only on Netlify, never in the browser. Then Admin → Servers → Admin assistant → tick "Use it". Each message you send is one paid AI call.
3. Redeploy. No new dependencies were added.

## What changed
- Servers: AniList and TMDB tabs; each tab shows and edits only its own servers; saved in this browser and in an admin-only Firestore document.
- Safe replace: pick servers, SUB/DUB tracks and titles (or a series' seasons), preview old/new links and un-mappable episodes, type REPLACE to confirm. Only selected slots change; slots that can't get a new link are emptied and listed. Live episode lists, the admin records and library counts are updated together. A "Delete links" mode removes a server's imported links the same way.
- Removing a saved pattern now says it only removes the pattern.
- Deleting episodes or a whole anime also removes the matching admin-record copies (no stale duplicates).
- Episodes page: "Add new episodes to this anime" heading, plus "Bulk import / update" and "Replace server links" shortcuts.
- Admin overview: Watching now, Total visits, Unique visitors; Storage report (read-only); Admin activity list.
- Requests: viewers see the request status in the dialog.
- Phone/player: names open details again everywhere except the watch page, where only the poster does; player background transparent (black in fullscreen); more space under phone controls; non-blocking font loading; larger save button on phone cards; New Releases cards smaller; new TYSHI ZONE favicon set.
