# TYSHI ZONE v18.0.2

## Watch page and seasons
- Season tiles are landscape rectangles. The open title stays crisp and receives the strongest accent; other main-story artwork stays visible under a darker, soft blur.
- Main-story `SPECIAL` entries in the AniList prequel/sequel chain now appear with seasons. Attack on Titan's two Final Chapters specials get distinct Part 1 and Part 2 labels instead of being put in Related with duplicate labels.
- Removed the visible “Current” badge from franchise cards. Selection remains clear through the active card treatment.
- Replaced the bright glass frames on the episode and related panels with dark matte surfaces.
- The watch-page search still collapses smoothly toward the left edge, reaching its compact state after one typical scroll.

## Layout and navigation
- The document keeps a stable vertical scrollbar gutter so switching SUB/DUB is less likely to shift the page horizontally.
- Existing Lucide navigation icons keep their shapes and transparent styling, with larger desktop and phone sizes.
- Phone New Releases cards are a little wider while preserving the desktop card count.

## Protections and existing behavior
- Iframe sandboxing and ad-shield behavior are unchanged.
- Existing spotlight fade, frame-limited dragging, and deferred home sections are retained.
- No features or saved data formats were removed.

## Install and run
From the extracted project folder containing `package.json`:

```sh
npm install
npm run dev
```

Create a production build with `npm run build`.
