# TYSHI ZONE v19.15

## Fixes
- **Long shows (One Piece, Bleach, Naruto, Black Clover) wouldn't open.** `anime.$id.watch.tsx` still referenced `q`, the episode-search variable removed in v19.12. It was only evaluated when a show had more than 50 episodes (`pages > 1 && !q`), so those pages crashed. Removed the stale check.
- **Search page:** removed the "Include 18+ titles" checkbox. Search always returns every title.
- **Poster bookmark:** smaller icon (20px -> 16px) and moved to the top-right corner on phones. The tap area is still 44px (invisible extension). Desktop button unchanged.
- **Home rails touch both screen edges:** Trending and New Releases were clipped 12px short of each edge by `content-visibility:auto` on their wrapper. `NearViewport` now has a `bleed` option that extends the wrapper to the screen edges on phones. Removed the duplicate negative margins in `AnimeRow` and `LatestEpisodes`.
- **Episode list view:** list view (not grid) now has its own scroll area, about six rows tall, with a thin scroll bar in the theme colour (new `scroll-theme` utility). It opens scrolled to the episode that is playing. Grid view is unchanged and has no scroll bar.
- **Search bar flicker on Watch Now:** the loading skeleton and the real page each render their own shell, so the search bar was rebuilt at full width and animated down to size. A freshly created bar now snaps straight to its resting size.
