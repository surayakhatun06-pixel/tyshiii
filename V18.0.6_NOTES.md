# TYSHI ZONE 18.0.6

- Mobile header is back to one clean row: logo, compact search, settings, and account. Scrolling the watch page collapses search left in one smooth step.
- New Releases cards now match the site's standard 128px phone poster size, including while loading.
- Poster save controls use a small bookmark on phones.
- Phone player is edge-to-edge horizontally. Add-to-list, Sub/Dub, server, and more controls stay on one row.
- Season tiles scale with the available width and all seasons remain visible without an inner scrollbar. Related still scrolls, and wheel/touch scrolling can continue to the page when the list reaches its edge.

## Run locally

1. Install Node.js (LTS).
2. Extract this archive.
3. Open a terminal in the extracted folder and run `npm install`.
4. Run `npm run dev` and open the local URL printed by Vite.
