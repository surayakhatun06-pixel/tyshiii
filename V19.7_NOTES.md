- Related sections now use a narrower set of AniList relation types and keep recommendation cards in “You Might Also Like.”
- New Releases fills the phone viewport; common mobile page and row gutters are smaller.
- Dub now lists recently aired episodes only when that exact episode has a DUB stream on the site. It no longer sorts titles by website edit timestamps. The date comes from AniList's airing schedule because the current episode data has no separate dubbed-release date.
- Episode list scrolling now chains to the page at the end, and default list labels read “Episode 1,” “Episode 2,” and so on.
- Season cards have clearer borders, a theme-coloured active border, and a soft blurred glow.
- The notification button matches the transparent Settings button. Theme accents tint the site gently, and Settings options are grouped into clearer cards.
- Phone watch information is balanced and centered, the phone player has square corners, and larger edge gutters allow scrolling beside the embedded player.
- Submitting the header search with Enter now prevents the key event from reaching the episode filter and navigates to `/search?q=…`.
