# TYSHI ZONE 18.0.5

- Mobile top bar now keeps the logo and account/settings controls on the first row, with a full-width search field directly below. The fixed header has matching page spacing on non-home screens.
- Mobile New Releases cards are slightly narrower while remaining large enough to browse comfortably.
- Mobile pages no longer pan sideways; the spotlight still handles horizontal swipes itself.
- On phones, the watch page order is Episodes, Seasons, anime information, then Related. Desktop keeps anime information beside the player and the original section order.
- Season tiles scroll inside a compact panel on phones. On desktop, all seasons flow down the page without a nested scrollbar. Related shows more entries before its scrollbar.
- The phone navigation targets are 48px high, and the vector white logo remains crisp on transparent backgrounds.

## Run locally

1. Install Node.js (LTS).
2. Extract this archive.
3. Open a terminal in the extracted folder and run `npm install`.
4. Run `npm run dev` and open the local URL printed by Vite.
