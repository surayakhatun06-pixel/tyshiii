# TYSHI ZONE v17.5 (on top of v17.4; read V17.4_NOTES.md for the Firebase / Netlify steps)

## Changes
- **Series name opens details on desktop.** On the watch page the series name and the poster both open the details page on computers (the name is no longer selectable text). On phones only the poster opens details there; everywhere else the name opens details again.
- **Bulk Import: "Links that already exist".** After choosing entries and servers, step 4 shows, per server and per SUB/DUB track, how many episodes already have a link and how many differ from the new one. Tick "Replace the N existing links" for only the servers/tracks you want, or use "Replace all existing links" / "Keep all existing". Unticked tracks, other servers, and servers you didn't switch on are never changed. A new server (for example Server 3) just adds its links. The admin series records follow the same choice as the live site, so they no longer disagree.
- Existing links that the new pattern cannot rebuild (for example no TMDB mapping) are kept and counted in that panel; use Servers → Replace links to empty them.
- **Watch page search bar.** It starts narrower, glides left and shrinks smoothly as you scroll, and ends as a magnifier button; tap it to open the full box again.
- **Polish.** Faster touch response (no tap delay), shorter animations on phones, calmer text-selection colour, clear keyboard focus rings, stable scrollbar on desktop.
