# TYSHI ZONE v17.6 (on top of v17.5; Firebase/Netlify steps from V17.4_NOTES.md still apply)

## Publish the Firestore rules again
`firestore.rules` changed: a viewer may now request an anime that is only in the library with no episodes (before, any existing library entry blocked the request). Copy the file into Firebase console → Firestore → Rules → Publish.

## Changes
- **Watch Now on a missing anime** now shows the request dialog. "Available" now means at least one episode link exists (an anime that is only in the library, or whose episodes were all deleted, counts as missing).
- **Back button in admin** goes back to where you were (for example the anime's admin page); Overview is only the fallback.
- **Requests:** pressing "Added (remove)" deletes the request so it leaves the list.
- **Bulk import, TMDB:** after choosing a TMDB series, "Add every season from TMDB" imports all its seasons as separate entries (works for shows that are not on AniList). "It's an anime: match it on AniList" keeps the old path.
- **Bulk import, replacing links is now automatic and clear:** servers you leave switched on are replaced. A panel lists, per server and SUB/DUB, how many links stay (identical) and how many old links will be deleted and replaced. The Import button asks you to press again ("Yes, delete N old links and import"). Servers switched off are never touched. Old links the new pattern cannot rebuild are deleted after the import.
- **Servers page simplified:** the pattern's mode (AniList/TMDB) follows the placeholders you type; shorter hints; the find-and-replace and delete-links tools moved into collapsed "Advanced" sections.
- **Episodes page:** SUB and DUB importers are compact; the small PC icon picks a .txt file from your computer, the small drive icon uses links saved in this browser, and "Paste links instead" opens the paste box.
- **Watch page (Miruro style):** under the episode tray there is a Seasons panel (picture tiles: Season 1, 2, 3…, current one marked) and a Related list (movies, OVAs, specials, side stories). The bigger poster and info card sit under the player on desktop and under the episode tray on phones. The series name opens details on desktop only; the poster always does.
- A soft fade behind the floating search bar stops text running under it.

## Not verified
