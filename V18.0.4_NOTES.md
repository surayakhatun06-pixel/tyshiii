# TYSHI ZONE 18.0.4

- Poster cards now lift and enlarge as a whole on hover, with extra carousel space so the effect stays visible.
- Season and Related panels use the same glass border as the anime information card. Their lists have practical height limits, touch scrolling, and a visible scrollbar on desktop when hovered or focused.
- SUB/DUB, server, list, and extra player actions now sit inside a single glass control panel.
- Replaced the black tile favicon with a larger white wheel mark on a transparent SVG canvas. The sidebar logo uses the same asset.

## Run locally

1. Install Node.js (LTS).
2. Extract this archive.
3. Open a terminal in the extracted folder and run `npm install`.
4. Run `npm run dev` and open the local URL printed by Vite.
