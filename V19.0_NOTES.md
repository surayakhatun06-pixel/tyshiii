# TYSHI ZONE v19.0

- Restored the reference episode grid: five compact columns, number-only buttons, a highlighted selected episode, and the existing three-line detailed list mode retained.
- Restored normal page scrolling through the full episode grid and Related list on phone and desktop, avoiding nested scroll regions that trapped touch gestures.
- Generic embeds now stay inside the site's responsive iframe for fullscreen instead of entering the provider's cropped fullscreen mode. Added a site-owned fullscreen button that expands the complete player frame to the viewport. The iframe ad-shield sandbox remains unchanged.
- Archive naming follows the requested two-part release sequence: `v19.0`, then `v19.1` through `v19.10`.
